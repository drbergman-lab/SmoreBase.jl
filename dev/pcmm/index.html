PhysiCellModelManager

If your complex model is a PhysiCell agent-based model run through PhysiCellModelManager.jl (PCMM), loading PCMM activates SmoreBasePhysiCellModelManagerExt, which adds CMData and CMSample methods that take PCMM objects directly:

using SmoreBase, PhysiCellModelManager
initializeModelManager("path/to/project")

sampling = Sampling(1)   # e.g. a GridVariation over two parameters, 4 replicates per point

data = CMData(sampling; cell_types="default", time_unit=:h, obs_times=[24.0, 48.0, 72.0])
# data.μ, data.σ: [3 times × 1 cell type × 1 condition × n_monads]; data.times in hours

cm_sample = CMSample(sampling)
# cm_sample.params: [n_monads × n_varied], one row per monad, one column per varied ABM
# parameter (named in cm_sample.names). Row k is the parameter set of data.μ[:, :, :, k].

Each PCMM Monad becomes one CM parameter set: μ is the replicate mean and σ the sample standard deviation of the population count of each requested cell type.

Time units. PhysiCell saves in minutes, so by default data.times and obs_times are in minutes. Pass time_unit (:h, :d, … — the symbols PCMM's own plots accept) to get both in another unit.

Zero or missing SDs. Where every replicate agrees (typically t = 0) σ is 0, and with a single replicate it is NaN. CMData keeps these as they are; SMFitProblem rejects them when the loss is GaussianNLL, since the likelihood is undefined there. Leave such times out with obs_times, or fit with a CustomLoss.

Reading speed. PCMM computes a simulation's population counts by parsing all of its output snapshots, then saves the counts in that simulation's summary/ folder. The first CMData call on a set of simulations therefore pays the parsing cost; any later call — say, with different obs_times or cell_types — reads the saved counts and is much faster.

SmoreBase.CMData — Method
CMData(T; cell_types=:all, include_dead=false, time_unit=:min, obs_times=nothing, time_tol=1e-6)

Build a CMData from PhysiCellModelManager.jl (PCMM) output: one CM parameter set per PCMM Monad, holding the replicate mean (μ) and sample standard deviation (σ) of the population count of each cell type. Available after using PhysiCellModelManager.

Arguments

T may be

  • a Sampling or Trial, or the PCMMOutput that run returns for one: one CM parameter set per monad it contains;
  • a vector of Monads: one CM parameter set per monad;
  • a Monad: one CM parameter set from its replicates;
  • a vector of Simulations from one monad: one CM parameter set from those replicates only (an error if they come from different monads);
  • a Simulation: one CM parameter set from that single run.

Keyword arguments

  • cell_types — :all (default: every cell type in the model, sorted by name), one name such as "default", or a vector of names. Each becomes one CMData variable, in that order.
  • include_dead::Bool=false — also count dead cells.
  • time_unit=:min — unit of the returned times and of obs_times. PhysiCell saves in minutes; pass :h or :d (also :s, :w, :mo, :y; the same symbols PCMM's plots take).
  • obs_times — nothing (default: every save time) or the times, in time_unit, to keep. Each must match a save time to within time_tol (absolute, in time_unit); a requested time that was not saved is an error.

Returns

A CMData of shape [n_times × n_cell_types × 1 × n_cm_param_sets]. Parameter sets are ordered as monadsTable(T) sorts the monads (by every varied parameter, the first as primary key), and labelled "name=value, …" from the varied parameters, or "monad<id>" when none vary. CMSample(T) returns the matching parameter values, one row per parameter set in the same order.

All replicates of a monad must share save times, and so must all parameter sets (after obs_times selection), and every simulation must have the same cell types.

σ is not checked here: it is 0 where every replicate agrees (typically t = 0) and NaN for a single replicate. SMFitProblem rejects such data when the loss is GaussianNLL; drop those times with obs_times, or use a CustomLoss.

PCMM computes each simulation's population counts by parsing every output snapshot the first time they are requested, then saves them in the simulation's summary/ folder; later calls on the same simulations read that file instead.

Example

using SmoreBase, PhysiCellModelManager
initializeModelManager("path/to/project")

sampling = Sampling(1)
data = CMData(sampling; cell_types="default", time_unit=:h, obs_times=[24.0, 48.0, 72.0])
cm_sample = CMSample(sampling)   # row k = varied parameter values of data's parameter set k

SmoreBase.CMSample — Method
CMSample(T) -> AbstractCMSample

The numeric parameters that vary across the monads of T (a Sampling, Trial, PCMMOutput, or vector of Monads), as a [n_monads × n_varied] CMSample: row k holds the values of parameter set k of CMData(T), i.e. it lines up with the 4th dimension of the data arrays. Columns are named by PCMM's short parameter names; a regular grid (e.g. from a GridVariation) comes back as a GridCMSample. Non-numeric varied columns (e.g. differing config folders) are left out. Available after using PhysiCellModelManager.

Throws an ArgumentError if no numeric parameter varies (e.g. T is a single monad).

Example

cm_sample = CMSample(Sampling(1))
cm_sample.names    # varied parameter names
cm_sample.params   # [n_monads × n_varied]
